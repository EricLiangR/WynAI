## 已观测状态字段

列表 `statusInfo` 至少包含：`status`、`alarmStatus`、`executionTime`、`lastAlarmTime`、`lastErrorTime`。当前实例现有监控返回 `status=Failed`、`alarmStatus=true`，因此可以优先设计为 WynAI 的状态轮询和诊断入口，但不能仅凭这些字段推导异常原因或通知送达结果。

## 接入建议

1. 将监控管理封装为 Wyn V1 适配器，所有路径和请求模型集中管理，不把浏览器 Cookie 写入配置。
2. 首先解决 `{id}` 路由参数合同问题，再做详情读取；详情失败时保留明确的“Wyn 详情不可用”状态，不用列表摘要冒充详情。
3. 使用专用测试看板和低风险收件人完成一次创建、触发、通知、停用、恢复和删除闭环。
4. 将 `statusInfo` 轮询结果映射为 `AnomalyEvent v1` 前，必须确认执行记录、阈值版本和数据查询引用是否可追溯。
