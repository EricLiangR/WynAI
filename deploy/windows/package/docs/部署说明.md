# Wyn AI Windows 部署说明

## 支持环境

- Windows Server 2012 R2 或更高版本，x64
- 管理员权限用于安装 Windows 服务和配置防火墙
- 服务器可以访问 Wyn 服务和配置的 LLM 服务
- 默认使用 TCP 端口 8787、8788

发布包已包含 Node.js 18.20.8 和生产依赖，目标服务器不需要安装 Node.js，也不需要执行 npm install。Node.js 18 已停止官方维护，本兼容包用于旧版 Windows 的 UAT；正式生产建议升级到 Windows Server 2016 或更高版本并使用受支持的 Node LTS。

## 首次部署

1. 将 ZIP 解压到固定目录，例如 `D:\Apps\WynAI`。
2. 不要直接在 ZIP 压缩包中运行 BAT。
3. 编辑 `config\wynai.env`。如果文件不存在，首次启动或安装时会从模板创建。
4. 重点填写 `WYN_BASE_URL`、`WYN_TOKEN`、`LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`。
5. 右键以管理员身份运行 `install-service.bat`。
6. 安装程序启动服务并执行 `/api/live` 存活检查。
7. 局域网访问时，根据提示开放 8787、8788 防火墙端口。

默认访问地址：`http://服务器IP:8787`

## 运维脚本

- `install-service.bat`：安装并启动开机自启服务。
- `uninstall-service.bat`：停止并删除服务，保留配置、数据和日志。
- `start-service.bat`：启动服务。
- `stop-service.bat`：停止服务。
- `status.bat`：显示服务、便携进程、存活检查和 Wyn 健康状态。
- `configure-firewall.bat`：开放配置中的主端口和视图代理端口。
- `remove-firewall.bat`：删除 Wyn AI 防火墙规则。
- `quick-start.bat` / `quick-stop.bat`：用于临时验证，不建议长期代替 Windows 服务。

## 目录说明

- `app`：应用程序文件，升级时可替换。
- `config`：部署配置和密钥，升级时必须保留。
- `data`：分析运行历史，升级时必须保留并定期备份。
- `runtime\logs`：运行日志和 WinSW 服务日志。
- `runtime\node`：包内 Node.js 运行时。
- `runtime\service`：WinSW 服务包装器。

## 升级

1. 备份 `config` 和 `data`。
2. 运行 `stop-service.bat`。
3. 替换 `app`、BAT、`runtime\node` 和 `runtime\service`。
4. 保留原有 `config`、`data` 和 `runtime\logs`。
5. 运行 `start-service.bat`。
6. 运行 `status.bat` 检查服务。

## 故障排查

- 检查 `runtime\logs` 下的日志。
- 确认 8787、8788 没有被其他程序占用。
- 确认服务器能够访问 `WYN_BASE_URL`。
- `/api/live` 表示进程存活；`/api/health` 还会检查 Wyn 配置和连接。
- 修改 `config\wynai.env` 后必须重启服务。

## 安全注意

- 发布 ZIP 不包含真实 Token 和 API Key。
- `config\wynai.env` 包含明文密钥，服务安装时会尝试限制为 SYSTEM 和管理员可访问。
- 8788 是带 Wyn 权限的视图代理，不应直接开放到不可信网络。
